# unspoken

> *A story told through an Instagram DM — the one that started with hello and ended with silence.*

An interactive web experience that tells a story through an animated Instagram DM conversation. Watch it unfold in real time — the typing bubbles, the short replies, the seen-but-not-answered, and the silence that followed.

## Built with

- Vanilla HTML, CSS, JavaScript
- No frameworks, no dependencies

## Run locally

Just open `index.html` in your browser. No build step needed.
